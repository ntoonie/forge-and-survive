Health System — structure_health.gd
extends Node

@export var max_health: int = 100
var current_health: int

func _ready():
    current_health = max_health

func take_damage(amount: int):
    current_health -= amount
    if current_health <= 0:
        get_parent().queue_free()

func heal(amount: int):
    current_health = min(
        current_health + amount, 
        max_health
    )
Arrow Tower Logic

The tower needs to detect enemies in range. Use an Area2D with a large CircleShape2D as the "attack range." When an enemy enters, the tower fires a projectile.

Milestone 4.2
A* Pathfinding — Enemies Navigate to Forge
Goal

Enemies find a valid path to the Forge using Godot's built-in A* grid pathfinding. They walk along that path. They stop when they reach the Forge and deal damage.

Why A* Before SA?

A* is guaranteed to find a path. Simulated Annealing finds a good path. We need working navigation first. SA will replace/supplement A* in Phase 6.

Godot 4 AStar2D Setup
# In a pathfinding_manager.gd (Autoload)
extends Node

var astar = AStar2D.new()
const TILE_SIZE = 32

func setup_grid(tilemap: TileMapLayer):
    astar.clear()
    # Add all walkable tiles as AStar points
    var cells = tilemap.get_used_cells()
    for cell in cells:
        var id = _cell_to_id(cell)
        var world_pos = tilemap.map_to_local(cell)
        astar.add_point(id, world_pos)
    # Connect adjacent walkable tiles
    for cell in cells:
        _connect_neighbors(cell)

func get_path(from: Vector2, to: Vector2) -> PackedVector2Array:
    var from_id = astar.get_closest_point(from)
    var to_id = astar.get_closest_point(to)
    return astar.get_point_path(from_id, to_id)

func _cell_to_id(cell: Vector2i) -> int:
    return cell.x * 1000 + cell.y   # Simple unique ID
Enemy Following the Path — raider.gd
extends CharacterBody2D

const SPEED = 80.0
var path: PackedVector2Array = []
var path_index = 0

func set_path(new_path: PackedVector2Array):
    path = new_path
    path_index = 0

func _physics_process(delta):
    if path_index >= path.size():
        return  # Reached destination
    var target = path[path_index]
    var direction = (target - global_position).normalized()
    velocity = direction * SPEED
    move_and_slide()
    if global_position.distance_to(target) < 5.0:
        path_index += 1
Important: Update Path on Structure Change

When the player places a wall, it blocks a tile. You must call PathfindingManager.setup_grid() again to re-compute the grid, then recalculate all enemy paths. This is critical and is exactly the behavior SA will refine later.

Milestone 5.1
Day/Night Cycle — Phase Switching
Goal

The game alternates between Build Phase (day, 60 seconds) and Defense Phase (night, until wave cleared). A visible timer counts down. A clear visual change indicates the phase shift.

game_loop.gd — State Machine
extends Node

enum Phase { BUILD, DEFENSE }
var current_phase = Phase.BUILD
var build_timer = 60.0
var wave_number = 0

signal phase_changed(new_phase)

func _process(delta):
    if current_phase == Phase.BUILD:
        build_timer -= delta
        if build_timer <= 0:
            _start_defense_phase()

func _start_defense_phase():
    current_phase = Phase.DEFENSE
    wave_number += 1
    phase_changed.emit(Phase.DEFENSE)
    WaveManager.start_wave(wave_number)

func on_wave_cleared():
    current_phase = Phase.BUILD
    build_timer = 60.0
    phase_changed.emit(Phase.BUILD)
Visual Phase Indicator

During Build Phase: bright sky tone, yellow tint on world.

During Defense Phase: dark overlay via a ColorRect with dark blue color at 60% transparency layered over the world. This is cheap and effective.

Build Phase Rules
  • Player can gather resources and place structures
  • No enemies spawn
  • Countdown timer visible on HUD
  • Player can optionally end build phase early
Defense Phase Rules
  • Player cannot place new structures
  • Can still move and activate abilities
  • Wave ends when all enemies are dead
  • Wave cleared → back to Build Phase

Phase 6
AI Integration — Simulated Annealing
▼
Milestone 6.1
Understanding Simulated Annealing
SA in Plain Language
1
Start hot. The algorithm begins "hot" — it tries many random paths, even bad ones. Like a raider who is confused and sprints everywhere exploring options.
2
Pick a neighbor. Take the current path and slightly modify it (shift one waypoint). This is the "neighboring solution."
3
Is it better? Calculate a cost score: shorter path = better. Avoids traps = better. If the new path is better, always accept it.
4
Sometimes accept worse. Even if the new path is worse, accept it with probability P = e^(-ΔCost/Temperature). This prevents the algorithm from getting stuck.
5
Cool down. Each iteration, multiply temperature by 0.95. As temperature drops, the algorithm accepts fewer bad moves and "settles" on a good path.
6
Stop. When temperature is near zero, the algorithm is "frozen" on its best found path. Assign that path to the raider.
SA vs A* — The Key Difference

A* Pathfinding

  • Guarantees the shortest path
  • Always the same result
  • Ignores "soft" costs (traps, exposure)
  • Players can predict and exploit it
  • Fast and simple to implement

Simulated Annealing

  • Finds a near-optimal path
  • Varies each run (unpredictable)
  • Considers trap penalties & exposure
  • Adapts to your defense layout
  • Computationally heavier
Heat Meter — What It Shows Players
COLD
HOT

Cold (blue): Raiders are "committed" — they've locked onto a path. Predictable for a moment.
Warm (amber): Raiders are weighing options. Somewhat unpredictable.
Hot (red): Raiders are in full exploration mode. Erratic, probing every gap in your defense.

The Distraction ability spikes the temperature back to Hot, forcing re-exploration.

Milestone 6.2
Python Prototype (Before GDScript)
Why Prototype in Python First?

SA is tricky to debug in a running game. Python lets you visualize the path optimization in isolation, tune your cost function, and verify the algorithm is working before putting it in Godot.

sa_prototype.py — Minimal SA Pathfinder
import math, random

def cost(path, grid, traps):
    total = len(path)   # Shorter = better
    for cell in path:
        if cell in traps:
            total += 50  # Trap penalty
    return total

def neighbor(path):
    # Shift a random middle waypoint
    new_path = path.copy()
    idx = random.randint(1, len(path)-2)
    x, y = new_path[idx]
    new_path[idx] = (x + random.randint(-1,1),
                     y + random.randint(-1,1))
    return new_path

def simulated_annealing(initial_path, grid, traps,
                         T=100.0, cooling=0.95, iterations=500):
    current = initial_path
    best = current
    for _ in range(iterations):
        T *= cooling
        candidate = neighbor(current)
        dCost = cost(candidate, grid, traps) - cost(current, grid, traps)
        if dCost < 0 or random.random() < math.exp(-dCost / max(T, 0.001)):
            current = candidate
            if cost(current, grid, traps) < cost(best, grid, traps):
                best = current
    return best
Testing Your Python Prototype
  • Plot the initial A* path in blue
  • Run SA and plot the result in red
  • Add trap cells, re-run — verify SA avoids them
  • Once it works visually, port to GDScript
Milestone 6.3
GDScript SA Integration
sa_pathfinder.gd — GDScript Port
extends Node

const INITIAL_TEMP = 100.0
const COOLING_RATE = 0.95
const ITERATIONS = 300

var current_temperature: float = INITIAL_TEMP

signal temperature_changed(new_temp)

func find_path(initial_path: PackedVector2Array,
               trap_positions: Array) -> PackedVector2Array:
    var current = initial_path.duplicate()
    var best = current.duplicate()
    current_temperature = INITIAL_TEMP
    
    for _i in ITERATIONS:
        current_temperature *= COOLING_RATE
        var candidate = _get_neighbor(current)
        var delta = _cost(candidate, trap_positions) - \
                    _cost(current, trap_positions)
        if delta < 0 or randf() < exp(-delta / max(current_temperature, 0.001)):
            current = candidate
            if _cost(current, trap_positions) < _cost(best, trap_positions):
                best = current.duplicate()
        temperature_changed.emit(current_temperature)
    
    return best

func _cost(path: PackedVector2Array, traps: Array) -> float:
    var total = float(path.size())
    for point in path:
        if point in traps:
            total += 50.0
    return total

func _get_neighbor(path: PackedVector2Array) -> PackedVector2Array:
    if path.size() < 3:
        return path
    var new_path = path.duplicate()
    var idx = randi_range(1, path.size() - 2)
    new_path[idx] += Vector2(
        float(randi_range(-1, 1)) * 32,
        float(randi_range(-1, 1)) * 32
    )
    return new_path

func spike_temperature(spike_amount: float = 50.0):
    current_temperature += spike_amount
    temperature_changed.emit(current_temperature)
Integration with Raider

In raider.gd, replace the A* path call with SA:

func _ready():
    var a_star_path = PathfindingManager.get_path(
        global_position, forge_position

⚠️ Performance Warning
SA runs 300 iterations per enemy. With 20 enemies in a wave, that's 6000 iterations per frame if you're not careful. Compute paths at wave start, not every frame. If performance dips, reduce ITERATIONS or run SA on a thread with Thread.new().

Wave Difficulty Scaling
func get_wave_config(wave: int) -> Dictionary:
    return {
        "enemy_count": 3 + wave * 2,
        "enemy_health": 50 + wave * 10,
        "enemy_speed": 60 + wave * 3,
        "sa_initial_temp": max(20.0, 100.0 - wave * 3.0)
        # Lower initial temp = smarter raiders earlier
    }
